## Why this variant has precedence

The choice is based only on evidence available before the P2 result and on architectural defensibility:

1. **Directly addresses the established bottleneck.** P1 showed that membership expansion can nearly double macro F1 but can dilute a small number of catalogue matches. P3-crossfit tests whether a family-direction transports to seeds that were not used to fit that fold model before allowing expansion.
2. **No rejected-parent membership dependence.** Unlike the consensus variant, P3-crossfit does not make the scientifically rejected P1 membership assignment part of the new detector input.
3. **Minimal architectural departure.** It preserves canonical P2 features, logistic model, candidate windows, weighting and conflict rule, adding only a self-supervised reliability gate. This makes causal interpretation and external transport cleaner.
4. **Avoids an additional hard physical cutoff.** Unlike the dual-null variant, it does not newly impose an absolute `D_SH < 0.05` membership gate on top of P2's learned two-view representation, reducing the risk of suppressing genuinely dispersed weak streams.
5. **Same promotion standard as P2.** It retains P2's no-regression, macro-F1, and large-shower recall/precision gates rather than changing the substantive definition of success.

These reasons are fixed without knowledge of whether P2 later passes or fails.

Technical/integrity P2 failure never activates P3. It requires equivalence-preserving P2 repair.

A genuine P2 development PASS continues through its already-frozen matched-literature and external/generalization gates.
