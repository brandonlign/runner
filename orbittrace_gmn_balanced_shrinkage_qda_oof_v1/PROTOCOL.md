## Sole scientific change: equal-prior shrinkage QDA score

Using the **same** separately fitted `Sigma_pos` and `Sigma_neg` already defined above, require each covariance to be finite, symmetric to absolute tolerance `1e-12`, and positive definite.

For a held-out z-vector `x`, define:

`D_pos = (x-mu_pos)^T Sigma_pos^{-1} (x-mu_pos)`

`D_neg = (x-mu_neg)^T Sigma_neg^{-1} (x-mu_neg)`

and compute the finite log determinants `logdet_pos = log(det(Sigma_pos))`, `logdet_neg = log(det(Sigma_neg))` using a stable signed-log-determinant routine, requiring positive determinant sign.

The sole raw QDA score is the equal-prior Gaussian log-likelihood ratio with common dimensional constants cancelled:

`q(x) = 0.5 * [D_neg + logdet_neg - D_pos - logdet_pos]`.

Positive values favor the recoverable class.

There is no empirical class-prior term, prior search, covariance pooling/interpolation, covariance estimator search, regularization search, diagonal approximation, feature subset, dimensionality reduction, QDA/Fisher blend, probability calibration, threshold, clipping, or nonlinear post-transform.
