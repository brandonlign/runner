# OrbitTrace P1 final blind Stage-A protocol

## Status

Protocol-only preregistration, frozen before any P1 development result, before any P1 matched-literature result, before any P1 MAARSY 2018/2019 result, and before any target-containing final search.

This protocol changes no P1 scientific rule. It freezes how an eventually promoted P1 would be deployed on the previously withheld GMN target region.

## Eligibility

P1 Stage A is dormant unless all three exact upstream gates pass without retuning:

1. `PASS_PROBABILISTIC_MEMBERSHIP_P1_DEVELOPMENT` on the exact frozen GMN 2022/2023 target-excluded P1 development;
2. the separately frozen exact-row P1 Sugar/HDBSCAN benchmark is classified `BROAD_CATALOGUE_SUPERIORITY` or `SPARSE_STREAM_SUPERIORITY` against both comparator panels;
3. the pristine MAARSY 2018/2019 external membership validation frozen in PR #542 returns exact `PASS_P1_MAARSY_2018_2019_EXTERNAL_VALIDATION` with all integrity and power requirements satisfied.

Development PASS alone, literature superiority alone, external `INCONCLUSIVE`, scientific external FAIL, or technical/integrity failure cannot authorize target-containing execution.

The invalidated GMN 2024/2025 panel cannot substitute for item 3: repository history showed PR #453 / run `31235104333` already consumed its known-shower labels and F1 endpoints.

## Final discovery corpus

Stage A uses complete geometrically valid GMN **2022 and 2023** rows, including the previously withheld solar-longitude interval 20°–55°.

Opening that interval is an application of the already selected method, not a new tuning stage. No target reference or known-shower label value may be available while the full-region catalogue is generated.

The full-region geometry parser must preserve the exact promoted-v8/P1 input definitions and stable-ID semantics. Apart from removing the development-time 20°–55° exclusion, no row-validity, coordinate, speed, deduplication, source or time-window rule may change.

## Hard pretruth firewall

Before the complete Stage-A ranking and expanded memberships are durably frozen, the process may access only generic scientific row fields required by the frozen v8/P1 method and provenance needed to verify exact inputs.

It must not read or normalize catalogue shower-label values.

It must not have access to:

- withheld OrbitTrace target IDs;
- target coordinates, radiant, speed or orbit;
- target activity bounds or target identity/name;
- canonical target members;
- any historical target rank/recovery from earlier exploratory methods;
- any Stage-B reveal result.

The withheld target-reference artifact must not be downloaded, mounted, queried, hashed or named by the scientific Stage-A process.

The order is binding:

1. load complete 2022/2023 geometry with the target interval now included and shower-label values unavailable;
2. build the exact promoted-v8 recurrent seed/core families on those rows;

## Stage B

After successful Stage A, use only `orbittrace_final_exact_id_firewall_v2`.

Stage B may receive a scrubbed withheld reference containing exact stable `{id, year}` values only. It computes exact set intersections with the already-frozen P1 primary families. No coordinate/orbit/radiant/activity matching, nearest-neighbor search, family merging, member expansion, reranking or threshold change is allowed after target IDs become visible.

The already-frozen reveal verdicts remain unchanged:

- `FULL_BLIND_RECOVERY`: rank <=25 and at least 4 exact withheld IDs in each of 2022 and 2023, at least 8 total;
- `PARTIAL_BLIND_RECOVERY`: if no full recovery, rank <=100 with the same per-year/total exact-ID support;
- otherwise `NO_BLIND_RECOVERY`.

## Claim boundary

A qualifying Stage-B result would support the claim that a method selected on target-excluded development, matched literature superiority and independent cross-survey validation independently ranked a family containing substantial exact OrbitTrace membership when finally applied to the withheld target region.

It would not by itself establish dynamical distinctness from every known stream or prove that every historical OrbitTrace member belongs to the recovered family.

This protocol must not be modified in response to the P1 development result, literature result, external-validation result, Stage-A rank, or Stage-B overlap.
