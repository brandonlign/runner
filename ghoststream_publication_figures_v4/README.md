# GhostStream publication figures v4

This revision replaces the infographic-like v3 presentation with restrained journal figures. It removes oversized display titles, decorative colour blocks, rainbow palettes, promotional callouts, and redundant labels while retaining the underlying measurements and tests.

## Non-negotiable production rule

Do not use ChatGPT interface image generation or any generative-image tool for GhostStream scientific figures. Render figures programmatically from preserved evidence artifacts and inspect the exported manuscript pages at printed size.
