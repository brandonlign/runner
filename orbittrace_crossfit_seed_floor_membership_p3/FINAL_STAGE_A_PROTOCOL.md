Development/literature/external scientific failure or power-inconclusive external outcome blocks Stage A. Technical/integrity failures authorize only equivalence-preserving repair, never a weaker prerequisite.

The final discovery corpus is fixed to complete geometrically valid GMN 2022 and 2023, including the previously inaccessible solar-longitude 20°–55° interval.

## Exact P3 method

Run exactly the promoted P3 architecture with no full-region adaptation:

- construct the exact promoted-v8 recurrent primary-family architecture on the full 2022/2023 event universe using the already-frozen source semantics;
- exact primary ranking remains promoted-v8 multiplicity order;
- P3 observation/orbit features remain `[d_obs,d_orb]` with the same OAS Mahalanobis geometry and exact Southworth–Hawkins D_SH implementation;
- candidate/background windows remain ±5° and every family-direction requires >=128 local nonseed negatives;
- five family folds remain `first eight bytes of SHA256(family_id UTF-8) mod 5`;
- held-out reliability remains >=4 target-year recurrent seeds, minimum held-out seed probability strictly >0.5, and complete local-negative tail at/above that floor <=0.10;

- conflict resolution remains unit background odds plus strict maximum family responsibility >0.5;
- original v8 seeds never move and P3 additions never train, refit, recenter, seed growth or change rank.

No Stage-A parameter search, alternative fold, alternative seed-floor definition, threshold change, rescue channel or target-specific exception is permitted.

## Failure semantics

If any prerequisite identity, full-region parser interface, P3 source identity, cross-fit/model integrity assertion, pre-reveal freeze or output-schema assertion fails, Stage A is a technical/integrity no-result. Do not inspect target reference and do not reinterpret it as scientific non-recovery.
