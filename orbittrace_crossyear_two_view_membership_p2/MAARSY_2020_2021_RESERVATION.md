# OrbitTrace P2 — dormant MAARSY 2020/2021 pristine-panel reservation

## Status

Reservation only. Frozen before any P1 or P2 scientific result and before any MAARSY 2020/2021 event-level scientific value is read in the OrbitTrace project.

This file authorizes no data download, event-value access, scientific run, target-containing search, or P2 activation.

## Why reserve 2020/2021

The completed MAARSY scientific chain used only 2016/2017 and explicitly stopped at the first `data/2018/` archive header. Separate repository-history searches performed before this reservation found no MAARSY 2020 or MAARSY 2021 scientific PR/run. P1 now has a separately preregistered 2018/2019 external panel that remains unopened unless P1 first passes development and literature superiority.

MAARSY 2020/2021 is therefore reserved now as the next consecutive event-value-unexposed pair for P2 **only if** the normal scientific decision tree reaches P2 and a genuinely fresh panel is still required. This prevents a later P1 external failure from forcing P2 onto an already-consumed panel.

If any execution-time history audit discovers prior 2020/2021 event-level geometry, velocity, orbit, label, family, score, or other scientific-value access by the OrbitTrace project, this reservation loses its pristine status and execution must block rather than silently weaken the claim.

## Activation boundary

No 2020/2021 scientific value may be accessed under this reservation unless all prerequisites are satisfied:

1. v6 has been scientifically rejected under its frozen decision tree, or otherwise failed to achieve the required literature/generalization authorization without target access;
2. exact frozen P1 has been scientifically rejected at a preregistered gate, or has consumed its reserved 2018/2019 panel and failed its frozen external validation;
3. exact frozen P2 has passed its own target-excluded development gates without retuning;
4. any required P2 matched-literature comparison has been frozen before its outcome and has passed its preregistered superiority standard;
5. a separate P2-specific MAARSY 2020/2021 validation protocol has been frozen **before** opening any 2020/2021 event value;
6. an execution-only child passes a repository-history freshness audit and exact target firewall.

If P2 never reaches these prerequisites, 2020/2021 remains untouched.

## Non-negotiable inherited firewall

Any later P2-specific protocol must, at minimum:

- remove solar longitude 20°–55° before geometry, model fitting, membership assignment, ranking, or evaluation;
- preserve the already-established MAARSY geometry semantics and native orbit mapping unless pre-value public source proves an incompatibility;
- forbid `kepler`/orbit access until the complete P2 geometry-only membership/ranking payload is immutable and hashed;
- forbid OrbitTrace coordinates, identity, members, prior target rank/recovery, target-region GMN events, or target-containing outputs;
- treat an interface/power failure as such rather than retuning P2 or changing the reserved year pair after values are seen.

This reservation intentionally does not choose P2 external scientific thresholds. Those must be frozen in a dedicated protocol only if P2 legitimately becomes the active successor, but still before any MAARSY 2020/2021 event value is accessed.
