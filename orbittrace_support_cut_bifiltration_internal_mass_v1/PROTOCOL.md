## Sole new evidence: internal two-density persistence mass
For a support-cut candidate `S` with event set `E(S)`, and every frozen bifiltration component `B` in the same deterministic panel with event set `E(B)` and frozen two-dimensional persistence area `A(B)`, define

`M_2D(S) = (1 / |E(S)|) * sum_{B: E(B) subseteq E(S)} |E(B)| * A(B)`.

Interpretation: the bifiltration artifact partitions the positive joint annual-density threshold plane into cells whose connected components have exact memberships. `|E(B)| * A(B)` is event-mass integrated over the threshold cells on which component membership `B` exists. Summing only components wholly inside `S` and dividing by `|S|` gives the integrated fraction of the support candidate that participates in reportable joint-annual-density connected structure.

This allows a physically coherent support-cut candidate to receive recurrence evidence from a stable recurrent core even when weak/background members prevent the **entire** candidate from surviving a positive joint threshold. It therefore differs from the closed exact-match and whole-candidate-containment bridges.

Rules:
- use every frozen bifiltration component whose exact membership is a subset of `S`;
- use its already-frozen `persistence_area` exactly once;
- support sizes are exact event counts;
- no Jaccard/overlap tolerance or nearest component;
- no cross-generator candidate replacement;
- no pseudocount or floor;
- zero `M_2D` is allowed;
- no modal-contrast multiplication, addition, ratio, or numeric blend.

## Frozen catalogue order
Order the **complete** support-cut candidate list by:
1. `M_2D` descending;
2. inherited support-cut `modal_contrast` descending for exact `M_2D` ties (principally zero-evidence ties);
3. `family_hash` ascending.

This is lexicographic, not a weighted fusion. The inherited modal contrast is only a deterministic tie-break preserving the original candidate architecture where the new evidence is exactly equal.

## Stage 1 — zero-label structural reproduction gate
No shower labels are accessible. Reproduce and serialize the complete ranked candidate lists, then require all gates:
1. `candidate_capacity_all_8`: complete support-cut count >= K in all eight panels.
2. `pairwise_disjoint_all_8`: selected candidate memberships remain pairwise disjoint in all eight panels.
3. `positive_internal_mass_all_8`: at least one candidate has `M_2D > 0` in every panel.
4. `cross_scale_mean_not_lower_than_recurrent`: mean of the four bucketwise top-K fine→coarse mean-best-Jaccards is >= recurrent-EOM.
5. `cross_scale_nonlower_4_of_4`: top-K cross-scale Jaccard is >= recurrent-EOM in all four buckets.
6. `immutable_membership_and_budget_audit`: support-cut memberships, recurrent memberships, panel universes, and K values reproduce the frozen artifacts exactly.

The cross-scale metric restricts each coarse candidate to the fine subset universe, drops restricted memberships below support 4, deduplicates exact memberships, and computes for each fine top-K candidate the best Jaccard to the restricted coarse top-K list; bucket score is the unweighted mean.
