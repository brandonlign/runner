# Parent-Anchored Dominant-Core Regrowth (PADCR) v1

## Motivation and development status

DCR v1 failed for two separable reasons. Its strict-majority CMR memberships removed true shower members, and recomputing M₂D on those smaller memberships also changed the already-good discovery ordering. Post-result analysis of the frozen DCR catalogues showed only `181/240` Sugar-budget and `6/28` HDB-budget selected parent identities remained in the promoted support-pruned top sets.

PADCR v1 is a direct one-variable ablation of that failure. It changes no DCR membership. Each promoted support-pruned parent keeps the exact frozen DCR v1 membership attached to it, but its discovery position is restored to the exact promoted support-pruned M₂D parent ordering. Child/extraction M₂D is retained only as metadata and cannot change rank.

This method is designed after the DCR GMN development result was observed. GMN 2022/2023 is therefore explicitly exposed development evidence. OrbitTrace protected `[20°,55°]` events/canonical IDs/coordinates, the revealed target family, SonotaCo truth, and external-survey truth remain prohibited from construction.

## Frozen rule

For each of the eight exact target-excluded GMN sparse panels:

1. Load the exact sealed DCR v1 pretruth membership catalogue, SHA-256 `92e91dfa5fc8557f26d4be0238b3379e49c0845513e7f3e0e9ffc471343813c5`.
2. Map each DCR membership back to its promoted support-pruned parent by the frozen parent family hash.
3. Emit exactly one membership per support-pruned parent: the exact DCR v1 membership, unchanged byte-for-byte as an event set.
4. Order emitted candidates by the exact promoted support-pruned parent M₂D ordering. The refined child M₂D cannot alter discovery rank.
5. No new score, coefficient, geometric scale, modularity pass, majority threshold, size cutoff, or rescue parameter is introduced.

## Structural gate before GMN truth

The exact PADCR catalogue is sealed before hidden GMN shower truth is opened. It must be active in the top budgets and strictly reduce mean, p90, maximum, and size-biased top-budget family burden relative to promoted support-pruned v1. If any gate fails, truth remains unopened.

## Binding development evaluation

If the structural gate passes, reuse the exact byte-frozen BWM/PR #1377 hidden-label evaluator and capacity semantics. All ten inherited gates remain unchanged: nonlower support-pruned macro-F1 and `F1 > 0.5` recovery on Sugar, HDBSCAN, d=128, and d=1024, plus preservation of both published-configuration literature wins.

PADCR v1 is specifically an attribution test: a pass would show DCR's main scientific failure was ranking drift; a failure with parent ordering restored would isolate the remaining problem to hard membership substitution itself. A GMN pass authorizes only exact frozen non-GMN transfer before any generalization claim or full-GMN OrbitTrace characterization. No post-result ranking or membership rescue is authorized.
