# R1 claim boundary

A future R1 pass, if one occurs, would support only a separately named membership-expansion architecture. It would not retroactively change the frozen v8 result or v8 blind protocol, and it would not establish OrbitTrace recovery until a separately frozen blind application is authorized and executed.

R1 cannot claim superiority over Sugar, HDBSCAN, or another published method from the already-exposed SonotaCo 2023/2025 comparison. Any superiority claim requires a separately frozen matched comparison after R1 itself has been selected without using those comparison outcomes for tuning.
