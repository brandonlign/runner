# OrbitTrace recurrent-core expansion R1

This directory starts a **new, separately isolated method-development program** after the frozen v8 literature comparison established a specific catalogue-level weakness: v8 remains competitive in the extreme 4–9-member endpoint but loses substantial annual F1 for larger showers, while the frozen v8 seed/family architecture retains useful recurrent sparse structure.

R1 is not a post-hoc v8 retune. The promoted v8 commit, final v8 blind-discovery freeze, literature conclusions, and all v7–v12 no-go records remain immutable.

The research question is whether a high-purity recurrent seed family can be used only as a *seed* for a separately defined, label-free final-membership layer that improves moderate/large-stream recall without collapsing purity. Candidate ranking and seed discovery remain separate from final membership assignment.

Before any R1 scientific rule is frozen, the only authorized execution in this branch is the schema-only GMN column audit. No target-containing catalogue, OrbitTrace target information, excluded-interval event, Stage A, or Stage B output may be accessed.
