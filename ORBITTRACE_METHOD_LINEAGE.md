# OrbitTrace method lineage

This file is a navigation layer, not a new scientific result.

## Active / protected lineage

- **Original OrbitTrace discovery and paper lineage** — preserve all original HDBSCAN discovery/application material, frozen candidate provenance, paper-facing validation, publication figures, and target membership/reference material. Cleanup must not alter or remove it.
- **Fixed-4° / Mondrian-clique sparse-stream detector** — preserve as the independent sparse-stream recovery/benchmark lineage used in the project.
- **v8 pooled-year-centroid label-free sparse-support multiplicity** — protected promoted family-generation architecture and the basis of the current label-free deployment path.
- **v15 multiscale-consensus multiplicity** — current surviving low-density ranking architecture.
- **Canonical survey interface** — GMN, SonotaCo, and MAARSY are projected to one method-facing event schema before the common detector/ranker.
- **Current deployment qualification** — canonical rows -> exact label-free v8 proposal/component/family graph -> pooled v8 centroids -> common v15 multiscale ranking.
- **Current validation ladder** — preserve the frozen SonotaCo and MAARSY transport/firewall/evaluator contracts and the current gated applicability/literature/validation path.

## Historical no-go / inactive development lineages

The repository contains many scientifically useful negative results. They remain part of the record but should not appear as active executable alternatives. Their PRs/commits/artifacts are the archive of record.

Examples include:

- v7 and other pre-v8 recurrence/representation attempts;
- v9 support-overlap and v10-v12 successors that failed frozen promotion gates;
- v13 density-capped multiplicity and v14 cardinality-shrunk rank fusion, both permanent no-go methods;
- old post-core membership/halo expansion experiments (R1/P1/P2/B1 and related v1-v5 envelope/conformal variants) that are no longer the active methodology path;
- P-series matched-benchmark transport/recovery/probe branches superseded by the current canonical v8+v15 deployment path;
- old external-dataset structure probes/recovery wrappers after their panel was rejected, exposed, power-inconclusive, or superseded;
- DMS v15 eligibility work, which is an abandoned detour and not part of the fixed GMN/SonotaCo/MAARSY structure.

## Repository convention going forward

A method is **active** only if it is named in the active/protected section above or in a later explicit synthesis that supersedes this file. Failed experiments remain discoverable through Git history and closed PRs rather than through a large set of runnable Actions workflows and open draft PRs.

Closing a historical PR is archival bookkeeping only. It does not erase its commits, discussion, Actions runs, artifacts, preregistration, or scientific conclusion.
