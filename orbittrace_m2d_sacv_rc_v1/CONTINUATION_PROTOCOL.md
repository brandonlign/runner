This file is committed while the first binding target-excluded GMN RC-v1 run is still in progress.

1. If and only if the exact binding GMN verdict is `PASS_M2D_SACV_RC_V1_GMN_DEVELOPMENT`, execute one exact no-retuning transfer to the already-established exposed SonotaCo SACV benchmark using the identical annual-hypothesis enumeration, edge rule, component membership, component-selection ordering, support, radius, contamination, physical scales, and fallback. The transfer must freeze all outputs before SonotaCo truth opens. It must at minimum retain the existing SACV-v1 transfer's paired precision/F1 contract; no parameter or ranking change is permitted.

2. If and only if GMN and SonotaCo both pass, execute one final top-100 M2D target application. Stage A must receive no canonical OrbitTrace package and must freeze RC-v1 memberships for original M2D ranks 1..100. Stage B may then perform exact trajectory-ID intersection only.

3. Target success uses the already-established firewall: original M2D rank <=100, at least 4 exact canonical IDs in 2022, at least 4 in 2023, at least 8 total, and exact target F1 >0.5. Report exact membership size, overlap, precision, recall, F1, and original M2D rank.

4. No target-aware component choice, threshold, pruning, merging, parent switching, reranking, support/radius change, or post-target rescue is permitted. A failure is preserved.

Because the architectural motivation arose after the #1406/#1407 target reveal, success may establish a clean no-retuning extraction and prospective replication of the failure diagnosis, but it must not be described as if this exact RC-v1 architecture had been designed before OrbitTrace was revealed.
