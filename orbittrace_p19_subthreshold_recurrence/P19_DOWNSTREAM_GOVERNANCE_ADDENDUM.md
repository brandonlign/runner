# P19 downstream governance addendum

This addendum is governance-only. It does **not** modify the frozen P19 scientific source, recurrence rule, inherited constants, development data, ranking, evaluation, pass/fail gates, or active/repaired execution.

It supersedes only the downstream panel-selection language in `P19_PROTOCOL.md`.

## If P19 fails development

Preserve `FAIL_P19_SUBTHRESHOLD_RECIPROCAL_RECURRENCE_DEVELOPMENT` as a permanent no-go for the exact frozen rule. Return successor development to the same target-excluded **GMN 2022/2023** corpus under `../orbittrace_governance/DEVELOPMENT_AND_SELECTION_POLICY_V1.md`.

Do not reserve or open a new SonotaCo year because P19 failed.

## If P19 passes development

A pass makes P19 eligible for final-candidate consideration; it does not automatically open a matched benchmark.

If P19 is explicitly declared `FINAL_FOR_LITERATURE_TEST` after the required development/stress review, its only authorized final matched literature panel is the permanent **SonotaCo 2013/2014** panel defined in `../orbittrace_governance/FIXED_DATA_SPLIT_V1.md`.

No successor-specific fresh-panel search or year substitution is authorized.

A passing SonotaCo 2013/2014 literature test may activate the permanent **MAARSY 2020/2021** no-retuning validation route. Only satisfaction of that external requirement may activate the separately frozen blind OrbitTrace search.

The target firewall remains unchanged throughout.
