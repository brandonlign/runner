# GhostStream figure production rules

- Never use ChatGPT image generation or any interface image model for GhostStream scientific figures.
- Build every figure programmatically from preserved data and workflow artifacts.
- Keep figure source, exact inputs, dependencies, and validation in the runner repository.
- Use restrained journal styling: no decorative gradients, glow, infographic cards, oversized display titles, or synthetic illustration.
- Prefer direct data encodings, compact annotations, consistent typography, and printed-size legibility.
- Inspect the exported manuscript pages after every replacement; standalone figure renders are not sufficient.
