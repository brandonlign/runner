# CAMS portal recovery note

The primary Track-1 analysis uses the complete official 567-row NOP lookup and exact public source-matched orbits. The workflow additionally attempts a current GMN NOP-labelled population recovery from official monthly trajectory catalogues. The NASA CAMS portal API was traced to `https://meteorshowers.seti.org/api/meteor`, but the public client exposes daily visualization records rather than a documented archival orbit-export contract. It is therefore not treated as an authoritative replacement for the original NOP-004 member-orbit population.
