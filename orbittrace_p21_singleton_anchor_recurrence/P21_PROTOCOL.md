# OrbitTrace P21 — recurrent singleton-anchor quartet rescue

## Status

P21 is a preregistered contingency successor frozen **while the exact P20 one-shot development run is still in progress and before its scientific result is known**. It is dormant unless P20 returns a genuine scientific development failure. A P20 PASS leaves P21 unexecuted.

P21 is not a P20 threshold retune. P20 starts from retained fixed4 quartets that already pass the inherited anchor-multiplicity gate `MIN_ANCHOR_COUNT=2` but fail to form a two-quartet component. P21 attacks the next earlier family-generation bottleneck: exact label-free fixed4 quartet proposals that are generated by the frozen anchor/nearest-neighbor machinery but are discarded solely because their exact within-bin event set is supported by **one anchor rather than two**.

Only target-excluded GMN 2022/2023 remains development data. No SonotaCo 2013/2014 scientific value, MAARSY scientific value, OrbitTrace target information, target-containing candidate result, or scientific event in solar longitude 20°–55° may enter P21.

## Exact singleton proposal reconstruction

For each target-excluded development year, P21 reproduces v6 proposal generation byte-for-byte through the point immediately before the inherited `anchor_count >= 2` retention filter.

For each 10° bin:

1. reproduce the exact anchor list, ±15° pool, feature matrix, 128-neighbor query, 64-member first shortlist, 128-member audit shortlist, exact anchor-distance calculations, quartet selection, audit replacement, event-set local deduplication, score maximization, and anchor-ID accumulation;
2. preserve the normal v8 retained set `anchor_count >=2` unchanged for the complete v8 backbone;
3. define a **singleton proposal** as an exact locally deduplicated four-event set with `anchor_count == 1`;
4. remove every singleton proposal whose four event IDs overlap **any event in any normally retained fixed4 quartet in that same year**, whether or not the retained quartet later belongs to a component. This makes P21 test structure absent from the retained v8 proposal universe rather than create an alternate copy of already-retained evidence;
5. sort the remaining singleton proposals by the same label-free within-bin evidence order already used by v6 after the anchor-count term: larger exact quartet score, then lexicographic four-event ID tuple;
6. apply the inherited numerical cap of **512 singleton proposals per bin**. The number 512 is not fitted for P21; it is copied exactly from the v6 proposal-budget ceiling and bounds the new below-gate universe symmetrically;
7. assign a singleton stable ID from year, bin, and exact sorted event-ID tuple.

No known-shower label, target information, score threshold, learned model, density threshold, or post-result tuning enters singleton eligibility.

## Cross-year recurrence

P21 pairs singleton proposals across 2022 and 2023 only through the inherited v8 physical family scale:

1. a cross-year candidate pair must have exact inherited centroid distance <=1.5;
2. each singleton chooses exactly one nearest eligible singleton in the other year;
3. ties are resolved before labels by smaller exact distance, then larger partner quartet score, then lexicographic partner event-ID tuple;
4. retain only **mutual nearest-neighbor** pairs;
5. reported family membership is exactly the eight quartet events, four from each year; no event expansion, halo, interpolation, reassignment, or recursion is permitted.

## Hard-family novelty veto

P19 showed that a large below-component family universe can improve family-level F1 while also create alternate representations of regions already covered by v8. P21 therefore freezes a label-free geometric novelty veto using no new scale.

For every reciprocal singleton pair, compare its 2022 and 2023 quartet centroids with the corresponding pooled centroids of every exact v8 hard recurrent family. Reject the P21 pair iff there exists a hard v8 family such that:

- 2022 singleton-to-hard centroid distance <=1.5 **and**
- 2023 singleton-to-hard centroid distance <=1.5.

Thus a surviving P21 family must be geometrically outside the inherited hard-family recurrence neighborhood in at least one year. The same already-frozen 1.5 radius is used; no novelty threshold is fitted.

This veto is entirely label-free and is frozen before P20's result. It is intended to add genuinely uncovered recurrent geometry rather than duplicate a hard family's two-year locus.

## Exact duplicate handling

After mutual pairing and the novelty veto, exact full eight-event-set duplicates are removed deterministically only by exact equality. No Jaccard, overlap fraction, label identity, or learned merge threshold is permitted.

## Ranking

The exact promoted-v8 hard multiplicity ranking is the complete immutable prefix. P21 families are appended afterward and ordered before labels by:

1. smaller cross-year singleton-centroid distance;
2. larger minimum quartet score across the pair;
3. smaller maximum distance to the nearest hard-family centroid in the *non-covered* year, when a hard family exists; if no hard family lies within 1.5 in either year, this key is treated as positive infinity and therefore does not confer priority;
4. stable family ID.

To avoid ambiguity in item 3, the implementation must serialize the exact ranking-key values before labels. This key may only use hard-family geometry and inherited distance, never labels. If the nearest-hard calculation is awkward to represent identically, the fail-closed implementation may omit key 3 and use only items 1, 2, and 4; it may **not** substitute a new data-derived ranking signal. The implementation choice must be frozen and source-audited before P21 execution.
