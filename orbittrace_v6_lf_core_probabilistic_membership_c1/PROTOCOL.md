This succession is frozen before either v6-LF result so the successor cannot be chosen from benchmark outcomes.

## Membership model

For each exact v6-LF primary recurrent family:

1. Treat its original v6-LF event union as immutable seeds.
2. For each year separately, compute the seed centroid using circular mean solar longitude, circular mean Sun-centered longitude, median ecliptic latitude, and median geocentric speed.
3. Express seeds/candidates in the exact P1/C1 four normalized observation coordinates: wrapped solar-longitude residual / 4°, wrapped Sun-centered-longitude residual / 2° with latitude cosine correction, latitude residual / 2°, and geocentric-speed residual / 2 km/s.
4. Pool seed-only residuals across the two years after year-specific centering and fit exactly one OAS covariance per family.
5. Candidate stream region: exact 99% four-dimensional chi-square ellipsoid.
6. Local-background shell: exact 99%–99.99% four-dimensional chi-square annulus.
7. Conservative local background: exact one-sided 95% Garwood Poisson upper mean from shell counts.
8. Per-year stream amplitude: immutable current-year seed count plus only positive non-seed excess over conservative expected background inside the 99% ellipsoid, divided by 0.99 containment.
9. Compute Gaussian stream intensity for every compatible non-seed event.
10. Original seeds never compete, move, disappear, or change family.
11. If an event is compatible with multiple families, compete all compatible stream intensities simultaneously against the conservative background intensity; assign only the maximum-intensity family when normalized responsibility is strictly >0.5.
12. Added events never refit centroids/covariance/background/amplitude, never seed growth, never merge families, and never change candidate generation or rank.

No parameter search or nearby variant is authorized.
